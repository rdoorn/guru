## Iteration 2 (merge 898599f)

Gate: `make check` in the worktree and after the merge — flake8 clean,
mypy clean (67 files), 2058 unit tests, 6 Colima integration tests.

**Runner regressions, root cause.** One cause for both: the eval's
stable sandbox workdir was a fixed path under the system temp dir, and
guru's own unit tests (`TestSandboxCase`) delete and recreate that exact
path. Every concurrent `make test` — the worktree agents ran about sixty
pytest sessions during the suite — and the dogfood worker's own
`run_tests` of guru's suite inside the copy wiped the live copy. Checks
then failed on a missing directory (or saw a clean fresh copy: the 13 s
dependency case), and the controller's synthesis turn crashed in
`project_block()` on `Path.cwd().resolve()` with the cwd unlinked; the
eval CLI had never called `log.setup()`, so the exception vanished and the
pre-join stall line was taken as the answer. Fixes: sandbox root
overridable (`GURU_EVAL_SANDBOX_ROOT`) and isolated per pytest session;
copy identity (inode) verified after the run with a clear `COPY_LOST`
error; fixture pytest and every runner child get their own `TMPDIR`;
worker errors fail the case with the exception text; `_final_answer`
returns empty when the last user message is unanswered; the eval CLI
logs. Lesson recorded in the loop contract: never run `make test` while a
suite runs from the same machine without the isolation, and treat
"passed" with an empty answer as a failure.

**Gate hardening** (review Important 1–7): per-task `Tally` of deleted
files and gross removed lines across applied submits; gross instead of
net lines, blank/comment padding does not offset; emptied files count as
deletions everywhere (`emptied` section flag, stat, packet, test-file
rule); the copy's `.git` is mounted read-only and the baseline sha is
recorded in the copy marker, `diff`/`show_baseline` refuse on mismatch
and discard the copy; `code_health` refuses symlinks leaving the copy;
`show_baseline` unit tests; renames scanned only for unparsable diffs;
`is_test_path` widened; single `health_flags_from` path, deltas computed
only when the rules are not already suspicious, capped at 20 files;
`HOME=/tmp` and `XDG_CACHE_HOME` in the container; `sandbox_run` argv
documented as a JSON list.

**Grading.** Scale rewritten on intent; evidence nonce-fenced; error text
clipped; `bench.build_adapters()` public; no marker on an empty last
block; `grade --show` prints prompt, evidence, answer and a label stub for
hand grading. Re-grade of fa5c42d05059: Haiku 2/1/2, Sonnet 2/2/2 vs
hand 2/2/2.

Next (iteration 3): controller cache misses (dump consecutive requests),
panel question over the user request, repeat grading for agreement
numbers, the spawn-then-join same-round race the debugging surfaced.

## Iteration 3 (merge 16f081c)

Gate after the merge: flake8 clean, mypy clean (67 files), 2153 unit
tests, 6 Colima integration tests.

**Controller caching, root cause.** Request dumps (`GURU_DUMP_REQUESTS`)
showed system block and tools byte-identical across a controller's calls;
the messages differed: at every turn start guru rebuilt the native history
from neutral messages and flattened earlier tool rounds to text, so the
mailbox synthesis request never shared a prefix with the previous request.
Fix: neutral messages keep provider tool ids; both adapters rebuild a round
natively when ids are present (Ollama and old transcripts still flatten);
`apply_retention` keeps text-less assistant steps that carry tool calls.
After the fix a Sonnet controller reads its whole previous turn from cache
(3542 read, 2 uncached tokens on the mailbox turn). Haiku controller
requests stay under the 4096-token minimum; accepted (≈ $0.30 per suite).
Anthropic direct with thinking on flattens only the LAST tool round (the
API requires a thinking block there); not probed live, pinned offline.

**Panel and race.** `needs_security` is asked over the human request plus
the task (mailbox deliveries skipped, request capped at 1000 chars).
`spawn` registers children synchronously so a `join` in the same tool
round waits instead of reporting "none of those are your sub-agents"; a
`launch` that raises drains the pending set (no phantom child, no stuck
barrier).

**Grading.** `--samples N` (median, stability). On fa5c42d05059 with N=3:
Haiku 2/1/1 (stable 3/3, agreement 1/3 — consistently docks two literal
points), Sonnet 2/2/1 median (agreement 2/3, stable 1/3). Fast cases
explain-readme / logic-bug / security-only: both judges 2 (2,2,2), hand 2,
labels added. Cost ≈ $0.09 per three cases per judge per three samples.

**Review fixes** (second independent review, pass with reservations):
emptied-to-comment files count as deletions; the main agent's destructive
tally is per turn; the baseline sha is kept in memory and a missing or
rewritten copy marker is refused and cleaned up (no leaked copies);
`git diff --text`; controller hint gains "one worker per named concern";
stability excludes synthetic zero grades; tests never touch `~/.guru/guru.log`;
fixture scratch dir moved out of the copy (guru-as-fixture tests pass).

Suite 3 measures all of this; results below.
